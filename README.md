# 恒常性メモリアル 3年3組 — プレイ版

同じフォルダの `index.html` をブラウザで開くと遊べます。音楽・画像は同梱されています。フォルダ内の構成を保ってください。セーブはそのブラウザ内に自動保存されます。別のブラウザや端末には引き継がれません。

主人公の性別と恋愛対象をそれぞれ選べます。恋愛対象以外の人とも友達として交流できます。放課後は場所で能力を上げて交流し、下校の相手を選びます。数日おきの夜は能力を伸ばせます。人物・図鑑に手がかりが集まったら、正体と働きを推理してください。文化祭の夜に条件を満たした相手とのエンディングを選べます。

## 収録範囲

- 15人それぞれの固有イベント4本、会話4本、下校、外出、告白と卒業式の一言を収録。選択による反応と能力条件があります。
- 行事は脚本をもとに短く再構成しています。原仕様にある全体イベントの全分岐、体育祭のミニゲーム、懐中時計の伝言パズル、三人エンド、恒常性モニターは未実装です。
- 立ち絵は3年3組の90枚。背景はV4の素材と、このゲームのために生成した3枚を使用しています。
- BGMは音楽の卵（takai）。曲名と利用条件は `BGM_CREDITS.md` を参照してください。

## 2026-11-08 立ち絵と画面の更新

15人×6表情を、透明な背景を持つRGBA画像として再生成しました。ゲームは `assets/chars-alpha/` の画像を直接表示し、旧SVG輪郭マスクは使用しません。生成された透明度をそのまま保持し、輪郭を二値化する処理や画像全体のぼかしは加えていません。通常絵の顔・衣装・ポーズ・小物を参照し、表情だけを変えています。古流千鶴には赤いリボンの髪飾りを反映しました。

`portraits.html` で6表情を並べ、背景を切り替えて確認できます。生成方針と画像のSHA-256・透明度・描画範囲は `assets/chars-alpha/manifest.json` に記録しています。

会話窓はコンパクトな下部配置を維持し、スマートフォンで立ち絵が下へ沈む表示を修正しました。日付・放課後／下校／夜・場所・主要イベントの切り替わりに短いカットインが入ります。同じ場所でセリフを進めたり再描画したりするだけでは繰り返しません。動きを減らすOS設定ではアニメーションを省略します。

15人の攻略条件、性別・恋愛対象9通り、場面カットインと画像参照をプログラムで確認し、ブラウザで立ち絵・会話窓・画面操作を確認しています。BGMの2.4秒は曲を重ねて切り替える時間であり、2.4秒ごとに曲を変更する設定ではありません。

確認コマンド（Node.js）：`node tests/game.test.cjs`、`node tests/audio.test.cjs`。

# 恒常性メモリアル 3年3組 — プレイ版

同じフォルダの `index.html` をブラウザで開くと遊べます。音楽・画像は同梱されています。フォルダ内の構成を保ってください。セーブはそのブラウザ内に自動保存されます。別のブラウザや端末には引き継がれません。

主人公の性別と恋愛対象をそれぞれ選べます。恋愛対象以外の人とも友達として交流できます。放課後は場所で能力を上げて交流し、下校の相手を選びます。数日おきの夜は能力を伸ばせます。人物・図鑑に手がかりが集まったら、正体と働きを推理してください。文化祭の夜に条件を満たした相手とのエンディングを選べます。

## 収録範囲

- 15人それぞれの固有イベント4本、会話4本、下校、外出、告白と卒業式の一言を収録。選択による反応と能力条件があります。
- 行事は脚本をもとに短く再構成しています。原仕様にある全体イベントの全分岐、体育祭のミニゲーム、懐中時計の伝言パズル、三人エンド、恒常性モニターは未実装です。
- 立ち絵は3年3組の90枚。背景はV4の素材と、このゲームのために生成した3枚を使用しています。
- BGMは音楽の卵（takai）。曲名と利用条件は `BGM_CREDITS.md` を参照してください。

## 確認状況

15人の攻略条件と性別・恋愛対象の組合せはプログラムによるシミュレーションで確認しました。ブラウザの操作・画面表示・音声再生の実機確認は、実行環境の安全制限により行えていません。

## 2026-10-28 表示・音楽の修正

人物の全体を背景と混ぜていた描画を外し、90枚の立ち絵ごとのSVG輪郭で外側だけを隠す方式に変更しました。元の立ち絵PNGは変更していません。BGMは同じ曲を再開し直さず、場面の切り替わりに合わせて、ゆっくりクロスフェードします。下校の会話でも夕方の曲を維持します。既存セーブはそのまま使えます。

確認：90枚の輪郭データ、顔と制服の不透明領域、音楽の継続・切り替え・消音解除・連続操作、および15人のルート到達シミュレーションが通過。今回もブラウザ接続の不具合により実画面・実音声は未確認です。

2026-11-03：BGMは放課後、下校、夜、行事、外出、結末の場面に応じて切り替えます。同じ場面内の会話や反応では曲を維持します。
